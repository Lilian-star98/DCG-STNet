# 真实证据与正式训练第三版

本版本独立于旧资料包和第二版合成实验。当前任务是补齐可复核的科研证据；不预设提出模型一定优于基线，不将手填论文表值或合成轨迹当作真实测量。

- 原始单位保留，不擅自转换为km/h或用于CTM物理标定。两份公开速度文件没有提供本任务所需的道路流量/密度/转向观测。

- 五种基线均下载作者仓库并记录提交和文件哈希：Graph WaveNet、D2STGNN、CaST、PDFormer、STAEformer。网络与统一协议适配已分离；这不等于已复现作者论文分数。

## 为什么不能直接使用现有Q补值结果

`Q/around_traffic_mv_avg_15min_1km_completion.py`使用全部61天计算周平均后填补缺失数据，不能保证训练/验证/测试隔离。现有完成版速度文件没有原始缺失掩码，无法事后可靠撤销补值。严格Q实验必须取得补值前速度和掩码，或者明确将旧结果标为带有泄漏风险的探索性分析。

现有事件路段时间列表也没有充分证明类别是事故、天气或学校活动。真实flow不能由速度函数生成；缺失事件标签不能自动归入正常场景。资料需求详见 `data/evidence_v3/required_inputs.json`；逐项状态由 `experiments/audit_real_evidence_v3.py`生成。

## 模型与官方基线适配边界

主模型目前使用STCausalNet历史编码器和直接多时域预测头；动态图只在候选边上执行MLP，评估输出与原密集实现经过数值和梯度对照。公共单变量实验没有真实局部事件和控制，因此对应输入明确置零，使用真实时间特征；没有CTM物理上下文，不代表论文的完整物理反事实模型。

Graph WaveNet的旧Conv1d使用二维kernel并输入四维张量，在现代PyTorch上改用Conv2d，保持权重和卷积代数。D2STGNN保留作者网络，但统一训练没有启用作者的课程学习调度。CaST使用作者网络、向量量化与互信息项；边相关性只用训练数据，时延DTW只用输入历史。PDFormer采用作者FastDTW、KShape和Laplacian方法，语义图统计限制于训练期，避免原数据处理中的全时期统计。所有这些区别必须在论文中公开。

## 正式参数选择与训练

配置文件 `experiments/formal_v3_study.json`预先固定候选学习率/隐藏维度，每个模型3组配置、同一搜索种子17、最多100轮、早停15轮、batch=8；选择验证集全部12个时域MAE最小的配置，再以0—4五种子独立训练和测试。STAEformer/PDFormer保持作者默认网络尺寸，搜索学习率。

“最优参数”仅指所声明范围和计算预算内的验证最优，不能称全局最优。学习率搜索与测试结果严格隔离；中途失败保留日志并停止，不跳过难跑模型后宣称公平胜出。所有测试结果及不利结果均保留。公共基准的训练不证明真实Q事件或物理一致性优势。

首个真实训练轮次已完成：METR-LA全训练时段、hidden=32、lr=0.001，验证MAE=3.54249，约225.5秒。它仅用于运行与耗时检查，测试集没有评估，不能称已收敛或最优。正式全矩阵预计需要持续多天，实际时间取决于各模型早停与设备可用性。

## 物理标定如何完成

入口 `paper.formal.calibration`接受真实流量和独立密度，使用明确的SI单位、道路排序、参数边界和按日期留出的数据。三角基本图用稳健多起点拟合；检查自由流/拥堵样本数、Jacobian秩和参数边界，按日期块自助采样给出参数区间。只有速度时拒绝伪造容量、波速或阻塞密度。

拟合基本图之后，还必须用未参与标定的真实网络时段验证。网络验证另需实际转向比例、边界到达量、初始车辆/排队、路段长度/车道及必要的信号记录。实际计数应与区间出流比较，不能与FD瞬时流率混用。标定和测试文件均保存哈希，实际路段顺序必须一致。当前本机尚无满足该契约的真实记录，因此不输出冒充实测的标定结果。

## 独立事件与模型优越性

入口 `paper.formal.events`要求训练事件ID与测试事件ID互斥、文献/日志来源、公布和发生时间、处理路段与未受溢出影响的对照路段。合成控制权重仅用干预前数据拟合；按独立事件组重采样区间。该估计依赖平行趋势、无未控制共同干预等条件；代码不会自动认定这些条件成立。真实反事实不可直接观测，估计效应差异不能标为真实TED。

优越性分开检验：普通预测MAE/RMSE/MAPE；真实事件下的误差与效应估计不确定性；在可信校准/独立仿真上的完整物理约束与反事实误差；参数量、显存和运行时间。五种子配对检验以验证表现选参照，跨时域/数据集BH校正；支持较低MAE须同时满足方向和校正显著性。没有通过的假设如实报告，不预先写“全面优越”。

`paper.formal.report`逐格列出原稿值、实测值、差异和待运行状态。Table1与Table3完整模型METR-LA MAE分别2.72和3.45，原稿尚未说明差异原因；新代码不能调参去迎合两者。Table2—4在真实输入、相应消融和可比物理指标未就绪前保持待核验。
