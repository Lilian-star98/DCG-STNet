# 续训启动器修复记录

2026-09-22 自动续办核对确认协调器 PID 48928 的进程名、可执行文件和启动时间与 process.json 一致；检查点持续更新，协调器没有错误日志，源码与冻结协议哈希一致。

发现 PowerShell 7 的 ConvertFrom-Json 会把 ISO 时间转换为 DateTime，而旧启动器与格式化字符串直接比较，可能误判已运行的协调器并重复启动。现在按 UTC ticks 比较。Windows PowerShell 5 读取无 BOM 的 UTF-8 中文路径也会出错；脚本保存为带 BOM 的 UTF-8，并明确使用 UTF-8 读取 process.json。

验证：在当前 PowerShell 和独立 Windows PowerShell 中分别执行启动器，均返回 `Training already running: 48928`。没有启动第二个训练队列，没有修改 src 下的训练源码、训练配置、检查点或历史结果。
